ZAVQEL V12

Baseada na linguagem visual da V11, com refinamento de espaçamento para deixar as seções mais próximas sem perder a sensação de luxo.

Principais ajustes:
- Menor espaçamento vertical entre seções, especialmente no mobile.
- Mantida a hierarquia tipográfica e a estética preto/dourado/off-white.
- Certificado de Exclusividade mantido como parte central da narrativa.
- Coleção agora usa o frasco como imagem de produto, em vez do frasco desenhado em CSS.
- Monograma separado em arquivo próprio: monograma-zq.png.
- Frasco separado em arquivo próprio: frasco-zavqel.png.
- HTML/CSS/JS puro, pronto para GitHub Pages.

- index.html
- monograma-zq.png
- frasco-zavqel.png
